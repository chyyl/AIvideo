规则 A · 风格锚定

  • 每条提示词末尾固定追加风格后缀（见 STYLE-00）
  • 禁止再写 anime / 3d render / illustration / cartoon
  • 画质词统一：35mm anamorphic · subtle film grain
  • 不论内容多随机，后缀一字不改

规则 B · 光线四档

  • L1 晨雾玉青 5500K 逆光丁达尔
  • L2 正午琥珀 4300K 硬光短影
  • L3 黄昏金红 3200K 长投影
  • L4 夜蓝烛火 2800K 局部暖光
  • 换光不换画风，四档互相可衔接

规则 C · 取景与镜头

  • 统一 16:9，主体不压边，留 5% 安全区
  • 焦段只用 28mm / 50mm / 85mm 三档
  • 透视统一：低机位仰拍山势，平视拍人
  • 空气层必须有：雾、尘、雨或雪之一

规则 D · 负面清单

  • 卡通 / 二次元 / 3D渲染感 / 塑料皮肤
  • 霓虹过饱和 / 现代服装 / 现代建筑
  • 文字、水印、品牌标
  • 多手多指、面部过度磨皮、HDR
使用方式
  1. 用你的 AI 按卡片里的英文提示词出图，比例选 16:9 / 1920×1080。
  2. 把图片拖到对应卡片的虚线框里（或点击选择文件），会自动压缩并保存在本浏览器。
  3. 卡片右上角圆点变绿即表示该条目已就位，顶部进度条同步。
  4. 原始图片建议按卡片底部的文件名另存一份到 images/，便于版本管理。
  5. 点「导出全部提示词」可下载含全部卡片内容的 .md 清单。
