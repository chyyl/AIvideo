# 用文本 AI + 提问生成剧情（脚本片段）

> 配套工具：`aivscript`　｜　适用：短片、广告剧情、系列短剧切片
>
> 核心观点：**不要一句话让模型“写个剧本”。** 先用结构化提问把模糊想法压成事实，再让模型做“填空 + 扩写”，最后用批评式追问迭代。模型负责生成，你负责判断。

---

## 1. 为什么必须分轮提问

一次性提示词（“帮我写一个 90 秒悬疑短片脚本”）有三个必然失败：

| 失败 | 表现 | 根因 |
| --- | --- | --- |
| 泛化 | 故事像模板，谁都能用 | 缺少具体的人、物、地点 |
| 失控 | 8 个场景、30 个镜头，时长 5 分钟 | 没有时长预算与镜头上限 |
| 不可拍 | 写“他内心崩塌”，导演无法执行 | 没有区分“展示”与“讲述” |

分轮提问的本质，是把**编剧的隐性决策显性化**：先定约束（平台/时长/受众），再定内核（谁要什么），再定视听（怎么拍），最后定产能（能不能做出来）。

---

## 2. 六轮 · 42 问清单

> 用法：不必全部回答。每轮至少回答 2–3 个，回答越具体，后面越省事。
> 拿不准的题可以写“待定”，让模型先给 3 个候选，你再选。

### 第 1 轮 · 定位（先决定「给谁看」）

目标：确定题材、受众、平台与时长，避免后面反复返工。

1. 这条视频最终发在哪个平台？抖音 / 视频号 / B 站 / YouTube Shorts / 内部汇报？
2. 目标时长是 15 秒、30 秒、60 秒、3 分钟，还是 5 分钟以上？
3. 核心受众是谁？年龄、职业、他们此刻的焦虑或欲望是什么？
4. 你希望观众看完的第一个情绪是什么：爽、怕、暖、燃、困惑、被说中？
5. 这条视频是独立成片，还是系列中的一集？如果是系列，世界观已有哪些硬设定？
6. 有没有必须出现的品牌、产品、人物或口号？它们允许以什么方式出现？

### 第 2 轮 · 故事内核（决定「讲什么」）

目标：把模糊感觉压缩成一句可执行的故事。

7. 用一句话说：谁，想要什么，被什么挡住，付出什么代价？
8. 主角最想要的东西，具体到可以拍出来吗（一个物件、一句话、一个动作）？
9. 阻碍来自外部（对手/环境）还是内部（性格/记忆）？
10. 故事的转折点发生在第几秒？观众会在哪一刻意识到事情不对？
11. 结局是得到、失去、还是「以为得到其实失去」？
12. 如果只能保留一个画面让人记住，你希望是哪个画面？
13. 这个故事有没有真实原型或亲历细节？哪个细节最不可替代？

### 第 3 轮 · 人物与关系（决定「谁在动」）

目标：让人物具备可拍的外观与可说的话语方式。

14. 主角出场时在做什么？这个动作能暴露他的性格吗？
15. 主角的外形关键词是什么（年龄、穿着、一件标志性物品）？
16. 对手/阻碍者的动机是否成立？他自己相信什么？
17. 两人之间此前发生过什么？观众需要知道多少？
18. 谁在说谎？谎言的破绽放在哪个细节上？
19. 有没有一个「沉默的人」（旁观者/路人）承担情绪反应镜头？
20. 主角说话是什么风格：短句、书面、方言、口音、几乎不说话？

### 第 4 轮 · 视听（决定「怎么拍」）

目标：把文字转成可生成的分镜与提示词。

21. 视觉风格参考哪部片子或哪种摄影流派（冷峻霓虹、胶片颗粒、纪录片手持、广告棚拍）？
22. 主色调是什么？有没有一个贯穿全片的强调色？
23. 光源从哪里来？自然光、霓虹、屏幕光、单一顶光？
24. 画幅与镜头质感：16:9 / 9:16 / 2.35:1，广角还是长焦？
25. 声音设计：环境底噪是什么？有没有一个反复出现的音效？
26. 配乐情绪曲线怎么走？从哪里开始铺，哪里彻底静音？
27. 全片要不要字幕？字幕风格是叙述性、对白式，还是只有关键词？
28. 有没有必须避免的视觉元素（血腥、真实品牌、特定人群特征）？

### 第 5 轮 · 生产约束（决定「能不能做出来」）

目标：提前排除生成失败与返工。

29. 单镜头是否控制在 10 秒以内？超过的镜头怎么拆？
30. 有没有多人复杂交互、快速打斗、手部特写等生成困难镜头？
31. 人物一致性怎么保证：固定外观描述、参考图、还是同一提示词模板？
32. 需要几个场景？场景能否复用同一空间以减少生成量？
33. 是否需要口型同步？台词长度与镜头时长匹配吗？
34. 交付物只要脚本，还是同时要绘图提示词、视频提示词、配音文案、字幕文件？
35. 谁来验收？验收标准是「能看懂故事」还是「画面达到参考片水准」？

### 第 6 轮 · 打磨（决定「还差什么」）

目标：用苏格拉底式追问找出薄弱环节。

36. 把结局遮住，前面 80% 是否仍然成立？如果不成立，说明伏笔不足。
37. 删掉任意一个场景，故事还完整吗？如果完整，这个场景就该删或该合并。
38. 每一句台词，能不能用一个动作替代？能替代的就删台词。
39. 观众在第 3 秒会看到什么？如果不够抓人，前 3 秒要重做。
40. 片中信息是「展示」还是「讲述」？把所有「讲述」标出来改写成「展示」。
41. 如果预算只够拍 5 个镜头，你保留哪 5 个？这个排序就是真正的故事骨架。
42. 现在这版最让你不安的地方是什么？那通常就是需要重写的地方。

## 3. 把答案变成「创作简报」

把 1–5 轮的回答填进下面这张卡，**这张卡就是后续所有提示词的输入**。不要直接把聊天记录丢给模型。

```yaml
brief:
  platform: 抖音
  duration: 90s
  audience: 25-35 岁、加班到深夜的城市白领
  emotion: 被说中
  logline: 末班地铁里，她捡到一张写着自己名字的车票，却从未买过票。
  protagonist:
    want: 想知道票是谁放的
    obstacle: 列车即将到终点站，她必须下车
    cost: 承认自己一直在等一个不会来的人
  key_image: 空荡车厢里，一张车票贴在车窗上，车票上写着她的名字
  visual: 冷蓝霓虹 + 一处暖黄台灯；胶片颗粒；16:9
  sound: 地铁刹车声反复出现；结尾彻底静音
  constraints: 单镜头 ≤ 6s；不用真实品牌；不做多人打斗
```

> 关键：`key_image` 是整条片子的锚点。先有它，再谈结构。

## 4. 生成「一小部分」：单场戏的三步法

不要一次生成全片。全片交给工具（阶段 1→3），**单场戏**用人工提问 + 模型扩写，质量最高。

### 步骤 A：锁定这一场戏的功能

问模型（或问自己）：

```text
这场戏在全片中承担什么功能？如果删掉它，故事会缺哪一块？
它必须让观众新获得哪一条信息？这条信息能不能用画面而不是台词给出？
这场戏的结束状态，与开场状态相比，必须发生哪一个不可逆的变化？
```

### 步骤 B：让模型产出 3 个节拍方案，而不是直接写台词

```text
你是短视频编剧。基于下面的创作简报和场景功能，给出 3 组不同的节拍方案（每组 3 个节拍）。
每组必须包含：一个动作、一句台词、一个反应镜头。台词不超过 20 字。
只输出表格：方案 | 节拍1（动作） | 节拍2（台词） | 节拍3（反应） | 这一组的风险
```

挑选标准：
1. 选**信息靠画面**的那组；
2. 台词能被动作替代的，直接删台词；
3. 反应镜头必须给到「沉默的人」或环境，不要只拍主角。

### 步骤 C：把选中的节拍拆成镜头（喂给本工具）

```text
场景：INT. 末班地铁车厢 - 凌晨
节拍：
- [动作] 车厢只剩她一人，车窗上贴着一张车票
- [对话] 她（低声）：这不是我的。
- [动作] 她把票撕下，背面是自己的笔迹
风格：冷峻霓虹、胶片颗粒、16:9

要求：拆成 3–5 个镜头，总时长 20 秒，单镜头 ≤ 6 秒。
输出 JSON，字段与 aivscript DSL 的 shots 一致。
```

工具中的做法：把这三条节拍填进场景的 `beats`，点击「生成」时阶段 3 会按同一套提示词拆镜头；或直接粘贴 JSON 用 `convert` 导入。

## 5. 与工具一致的三阶段提示词

工具内置的提示词见 [aivscript/prompts.py](../aivscript/prompts.py)，TUI「提示词库」页可实时查看。三段的核心职责：

| 阶段 | 输入 | 输出 | 关键约束 |
| --- | --- | --- | --- |
| 1 · 立意 | 主题/类型/风格/时长/受众 | title、logline、人物、三幕 outline | logline 必须含目标+阻碍+代价；人物外观可直接绘图 |
| 2 · 场景 | 全片信息 + 本幕预算 | 场景 + 3 个左右节拍 | 台词 ≤ 20 字；场景之间有因果推进 |
| 3 · 分镜 | 场景 + 节拍 + 人物 | 镜头 + 中英提示词 | 单镜头 2–8s；至少一个建立镜头 + 一个情绪镜头 |

**共同输出纪律**（缺少会导致解析失败）：

```text
只输出一个合法 JSON 对象；键名英文 snake_case；不要 Markdown 代码块；不要解释。
不确定的信息给合理默认值，不要留空、不要写「待定」。
```

## 6. 批评式迭代：让 AI 当审稿人

生成完一版后，不要直接改字。先让模型**攻击**这一版：

```text
你是严格的剧本审稿人。下面是一版 90 秒短片脚本（YAML）。
请只做三件事，按严重程度排序，每条给出「第几幕第几场第几镜 + 具体修改动作」：
1. 找出所有「讲述而非展示」的地方；
2. 找出删掉也不影响故事的场景；
3. 找出观众会在第几秒失去耐心，为什么。
不要给鼓励性评价。
```

然后针对被点名的镜头，用「单镜头重写」提示词局部替换：

```text
保留叙事功能，换一个机位或景别重写这个镜头；时长保持 2–8 秒；只输出该镜头对象。
```

这样每次只改 1–2 个镜头，结构不会崩，也便于对比。

## 7. 常见失败模式与修复

| 现象 | 根因 | 修复动作 |
| --- | --- | --- |
| 每条提示词都像“电影感大片” | 风格词被复用到所有镜头 | 把 `style` 拆成「全局风格」+「本镜特殊光线」，只保留一个强调色 |
| 镜头全是大特写 | 模型偏好情绪镜头 | 在提示词里强制「至少一个 wide / extreme_wide 建立镜头」 |
| 人物前后不像同一个人 | 外观描述每镜重写 | 固定 `characters[].appearance` 原文，逐字复制进提示词 |
| 台词太长、口型对不上 | 未约束字数与时长 | 台词 ≤ 20 字；`duration ≥ 字数 / 4` 秒 |
| 总时长比目标多 40% | 没有时长预算 | 先算 `镜头数 ≈ 目标秒数 / 4`，再分配每镜时长 |
| JSON 解析失败 | 模型加了说明文字 | 用工具的「JSON 修复」提示词重试；或降低 temperature |
| 故事“正确但无聊” | 没有不可替代的细节 | 回到第 2 轮第 13 问：哪个细节最不可替代？把它变成关键画面 |

## 8. 快速上手（工具内）

```bash
# 1) 离线体验完整流程（无需 API Key）
python -m aivscript run --offline

# 2) 接入任意 OpenAI 兼容模型
export AIVSCRIPT_API_KEY=sk-xxx
export AIVSCRIPT_BASE_URL=https://api.openai.com/v1
export AIVSCRIPT_MODEL=gpt-4o-mini
python -m aivscript run

# 3) 无界面批量生成
python -m aivscript generate --theme "末班地铁里，她捡到一张车票" --genre 悬疑 --duration 90 --out output/demo.yaml
```

TUI 内的操作顺序：

1. 左侧填主题 / 类型 / 时长 / 画幅；
2. `Ctrl+A` 打开高级设定，填风格、基调、受众；
3. 点「生成」→ 日志显示三阶段进度；
4. 「分镜表」逐镜检查，`Enter` 选中后「编辑」或「重写」；
5. 「剧本预览」通读；「校验」看是否有 ERROR；
6. 「导出」一次写出 YAML / Markdown / JSON。

## 9. 一句话总结

**提问负责“想清楚”，模型负责“写出来”，批评负责“写得好”。**
三者缺一，AI 只会给你一份看起来像剧本、但拍不出来的文本。
